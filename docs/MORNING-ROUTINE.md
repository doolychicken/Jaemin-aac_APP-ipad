# 아침 일정 관리

첫 화면 또는 스케줄표의 ‘아침 일정’에서 엽니다. 기존 주간 일정과 저장 공간이 분리되어 있습니다.

- 날짜를 눌러 붙인 뒤 창밖을 보고 날씨를 선택합니다. 날씨는 자동 추정하지 않습니다.
- 다음 카드 하나만 보여 줍니다. 끌어 놓기 또는 누르기로 순서대로 붙입니다.
- 일정을 모두 붙인 뒤 ‘다 했어요’로 실제 완료한 단계를 표시합니다. ‘완료 한 칸 되돌리기’로 실수를 취소합니다.
- 보호자 설정은 선택한 날짜만 수정합니다. 삭제·추가·순서 변경 시 그날 붙이기와 완료 표시를 초기화합니다.
- 주말 기본 일정은 비워 둡니다. 보호자 설정에서 추가할 수 있습니다.
- 한국 날짜를 기준으로 시작하며, 재방문 시 해당 날짜의 날씨·배치·완료 상태가 복원됩니다. 최대 30일을 보관합니다.

## 기본 순서

월~수: 학교 → 점심 → 장애인 콜택시 → 강서 큰나무 병원 → 택시 → 집

목: 학교 → 점심 → 수업 → 장애인 콜택시 → 사람과소통 → 걸어가기 → 집

금: 학교 → 점심 → 장애인 콜택시 → 세브란스병원 → 푸르메 재활병원 → 버스 → 집

금요일 병원 사이 이동수단과 방문 시간은 입력하지 않았습니다. 큰나무·푸르메는 실제 사진이 준비되지 않아 병원 기호와 기관명을 표시합니다.

## 수정 위치

- 일정·문구·그림: `js/data/app-data.js`의 `morningRoutine`
- 동작: `js/features/morning-routine.js`
- 화면: `css/features/morning-routine.css`
- 검사: `python scripts/test-morning-routine.py`
- 저장 키: `jaemin-morning-board-v1`

문구를 바꾸면 음성 카탈로그·녹음·음성 묶음을 재생성하고 오프라인 캐시 버전도 함께 올립니다.
